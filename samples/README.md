# 出力のサンプル（高知県）

`output/corrected/` の8ファイルから、高知県（都道府県コード 39）の分だけを抜き出したものです。
スクリプトを実行しなくても、出力の形と中身を確かめられます。

施設票（助産所と薬局では唯一の票）は `都道府県コード` が `39` の行を残しています。
診療科の票は、残した施設の `ID` を持つ行だけを残しています。
行は出力の文字列をそのまま写しているので、列の並び、引用符の付け方、`注記` の文は全国の出力と同じです。

jp-healthcare-osm の `samples/` も高知県なので、同じ施設の OSM 向けの出力と見比べられます。

## 作り直し

```bash
npm run correct
npm run samples
```

出力の形を変えたときは、そのコミットで一緒に作り直してください。

## 出典

このサンプルには `座標の出典` が `地番` の行（11行）が含まれます。
再配布の際は、リポジトリ直下の README の「出典明示」の3行をすべて含めてください。
